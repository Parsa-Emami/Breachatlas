# BreachAtlas: Open-Source Contract

Project source is public under [Apache-2.0](LICENSE). The full supported local core includes the web UI, Go loopback engine, standalone offline verifier, analyzers, synthetic examples, tests, build recipes, and resource/provider instructions without paid/cloud accounts, proprietary entitlements, or sibling repositories. `package.json` `private: true` only prevents accidental npm publication.

Upstream dependencies retain their own licenses. All shipped dependencies are pinned and inventoried in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), `BUILD_RECIPE.json`, and the SPDX-2.3 SBOM generated by `scripts/package.sh`. Unknown or restricted resources cannot silently become required core dependencies, and optional hosted/commercial adapters cannot gate the local core.

Current status: `CORE_READY_LOCAL_USABLE` (`C30–C33` verified on `Linux x86_64` for local clone-to-value, reproducible packaging, loopback/private hosting boundaries, and keyboard/mobile UX). Full public OSS v1 certification is tracked in `C40` in [ROADMAP.md](ROADMAP.md). Contributing: [CONTRIBUTING.md](CONTRIBUTING.md). Agent instructions: [AGENTS.md](AGENTS.md). Vulnerabilities: [SECURITY.md](SECURITY.md).
